    Class ThreadPool<Arguments, Output>

    A static thread pool that will execute a task/function on different threads.

    ThreadPool

    Example

    import { ThreadPool } from 'nanothreads';

    const pool = new ThreadPool<string, string>({
    	task: (name) => `Hello ${name}!`,
    	count: 4
    });

    await pool.exec("Paul") // output: "Hello Paul!"

    Abstractterminate

    • terminate(): Promise<void>

      Kills each thread in the pool, terminating it

      Returns Promise<void>

      A promise that resolves when all threads have been terminated.

      Remarks

      After calling terminate(), the pool should not be used to execute new tasks. Any pending tasks that have not yet been assigned to a worker may be rejected or left unprocessed. Implementations should ensure that all worker threads are properly cleaned up and resources are released when terminating the pool.
